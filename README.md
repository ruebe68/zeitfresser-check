# Zeitfresser-Check

Geführter Fragebogen von Rübsteck Consulting für die Potenzialanalyse (KI-Agenten).

- `index.html` – die Seite (Du-Form; mit `#sie` am Link in Sie-Form)
- `google-skript.gs` – Apps Script für die Google-Tabelle, die die Antworten aufnimmt
- `fonts/` – lokal eingebundene Schriften (keine Verbindung zu Google Fonts)
